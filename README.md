# Hi, I'm Manish Katyan

I'm a founder-engineer and open-source maintainer who built **AdmissionTable.com through acquisition**. I design and ship products end to end—from React and Node.js applications to cloud infrastructure, media pipelines, developer tooling, and applied AI.

I care about pragmatic architecture, reliable systems, and software that solves a real operational problem.

## What I bring

- **Product engineering:** turning ambiguous problems into maintainable, production-ready applications
- **Full-stack development:** React, Node.js, APIs, integrations, payments, analytics, and internationalization
- **Platform and infrastructure:** Docker, AWS, automation, FFmpeg-based media workflows, and BigBlueButton at scale
- **Applied AI:** Python, LangGraph, multi-agent workflows, hybrid retrieval, reranking, and RAG
- **Open source:** building tools that developers adopt, extend, and contribute to
